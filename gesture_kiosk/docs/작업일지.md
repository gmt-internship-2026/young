### 1. 제스처 조작 체계 전면 교체

옛 방식(팔 좌우 쓸기 + 손가락 1개 정지 유지)을 버리고 새 체계로 바꿨다.

| 손 모양 | 이동 방향 | 결과 |
|---|---|---|
| ☝ 검지 1개만 편 채(point) | 좌/우/상/하 | 포커스 이동 (`left`/`right`/`top`/`bottom`) |
| ✊ 주먹(fist) | 우 / 좌 / 상 | 확인(`ok`) / 이전(`back`) / 처음(`home`) |
| ✊ 주먹 | 하 | **미사용** — 회사 스펙에 없음 |

- 손 모양과 이동을 **같은 MediaPipe 프레임**에서 함께 봐서 동기화 문제가 없다
  (`src/postprocess/gesture_filter.py`)

### 3. 손 모양(주먹/검지) 인식이 계속 불안정했던 문제 — 원인 3개를 순서대로 발견

실기에서 "카메라를 정면으로 가리키면 주먹/검지 구분을 잘 못한다"는 문제를
해결하는 과정에서 서로 다른 원인 3개를 차례로 찾아 고쳤다:

1. **깊이(z) 정보 누락** — `count_extended_fingers()`가 MediaPipe가 주는 z(깊이)를
   버리고 x,y 화면 좌표만 봐서, 손가락이 카메라 쪽으로 뻗을 때 원근 단축으로 짧게
   찍혔다. x,y,z 3차원 거리로 판정하도록 고침(`src/inference/hand_estimator.py`).
   이후 `extended_ratio`는 원래 값(1.3)으로 복귀
2. **손가락 개수 인식 흔들림** — 개수가 프레임마다 살짝 흔들리면(1→4→1 등) 그때마다
   이동 궤적이 리셋돼 거의 확정이 안 됐다. `miss_grace_sec`(0.5초) 유예를 추가해
   잠깐의 오검출은 무시하고 직전 모양을 유지하게 함(`gesture_filter.py`)
3. **사람 인식 박스가 손을 놓침** — 팔을 옆(오른쪽)으로 뻗으면 손목 키포인트
   신뢰도가 떨어져 사람 박스가 좁아지고, 그 박스로 손을 크롭하다 보니 손 자체가
   안 잡혔다. 박스 여유값(`person_lock.keypoint_bbox_pad_ratio`)을 0.10→0.4로 확장

그래도 규칙(임계값) 기반 판정이 계속 못 미더워서, **학습 기반 분류기**로 전환했다
(아래 4번).

## 참고사항 (날짜 무관 — 프로젝트 하면서 알아두면 좋은 것들)

### young과 GMtech_project는 완전히 다른 저장소다

폴더 이름·내부 구조(`gesture_kiosk/`)가 비슷해서 헷갈리기 쉽지만:
- `young/` → GitHub `gmt-internship-2026/young.git` — **실제 작업은 여기서 함**
- `GMtech_project/` → GitHub `G0Sun9M0/GMtech_project.git` — **다른 팀원 저장소**

`git remote -v`로 확인하는 게 가장 확실하다(VS Code 하단 브랜치 표시는 여러
저장소가 한 창에 열려 있으면 잘못된 걸 보여줄 수 있음 — 실제로 이번에 그 문제로
헷갈렸었다).

### GMtech_project는 여전히 병합 충돌(merge conflict) 상태다

이 PC의 로컬 커밋(`jaeyoung0710` 작성)과 팀원이 origin에 푸시한 커밋
(`G0Sun9M0` 작성)이 충돌 중 — 10개 파일이 미해결 상태로 남아있다. **사용자 지시로
건드리지 않고 그대로 두고 있음.** 나중에 정리가 필요하면 별도로 다뤄야 한다.

다만 GMtech_project의 origin은 팀 차원의 실제 스펙 변경(델파이 연동 방식,
제스처 이벤트명 등)이 반영되는 곳이라, 회사 쪽 결정이 바뀌었는지 확인할 때는
`git fetch origin`으로 참고할 가치가 있다(코드는 안 가져와도 정보만 확인).

### 윈도우 배치 파일(.bat)은 반드시 CRLF로 저장해야 한다

`chcp 65001`(UTF-8) 상태의 cmd.exe가 LF만 있는 배치 파일의 한글 텍스트를
잘못 파싱해서 알 수 없는 명령어 오류를 내는 걸 실기에서 확인했다(`collect_hand_shape.bat`
최초 작성 때 발생). 배치 파일을 새로 만들거나 고칠 땐 줄바꿈이 CRLF인지 꼭 확인할 것
— 기존 `run.bat`/`install.bat`은 전부 CRLF다.

### PowerShell에서 현재 폴더 스크립트 실행

`collect_hand_shape.bat` 같은 걸 그냥 치면 안 되고 `.\collect_hand_shape.bat`처럼
`.\`를 붙여야 한다(PowerShell 기본 정책).
