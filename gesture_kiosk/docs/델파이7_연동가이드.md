# 델파이7(Delphi 7) 연동 가이드 — 제스처 엔진 ↔ 회사 GUI 프로그램

> **2026-07-23 확정 — 파이프(stdio) 연동** (회사 요청: 엔진은 이벤트를 print만 한다).
> 델파이가 엔진을 자식 프로세스로 실행하고, 엔진이 표준 출력(stdout)에 찍는
> 텍스트 한 줄을 **익명 파이프**로 읽는다. 네트워크(UDP·웹소켓)는 전면 철회 —
> 포트·방화벽·유실 이슈가 소멸했다 (파이프는 같은 PC 안의 신뢰 채널이다).
> 엔진 쪽 구현: `src/pipeline/event_sender.py` (`StdioEventSender`).
> 델파이 쪽 완성 예제: **`delphi_ui/` 폴더** (포커스 이동까지 동작하는 데모 UI).

## 1. 통신 구조

```
델파이7 GUI 프로그램                          제스처 엔진 (python)
  CreateProcess로 엔진 실행  ─────────────►  run.bat / run_demo.py
  익명 파이프(stdout) 줄 단위 수신 ◄────────  이벤트 확정 시 print 한 줄
```

- 이벤트(엔진→GUI): stdout 텍스트 한 줄 — 이벤트 확정 순간 1건씩. 폴링 불필요.
- 같은 PC 안 파이프라 전달 순서 보장·유실 없음 (UDP 유실 협의 항목 소멸).
- 음성 안내(TTS)는 엔진에 없다 — 2026-07-22 제거, 회사 UI 담당.

## 2. 엔진 쪽 설정 (`configs/config.yaml`)

```yaml
event_output:
  mode: stdio             # 배포 기본값 — stdout에 이벤트 한 줄씩
```

로그는 stderr·파일(logs/)로만 나간다 — **stdout에는 이벤트 줄만 온다.**

## 3. 전송 규격 (text)

이벤트 1건 = ASCII 한 줄 (CRLF `#13#10` 종료):

```
GESTURE|이벤트명|손|신뢰도|시각\r\n
예) GESTURE|right|right|1.00|12345.678
    GESTURE|ok|left|1.00|12346.912
```

| 필드 | 값 | 비고 |
|---|---|---|
| 1 | `GESTURE` 고정 | 규격 식별자 — 다른 줄은 무시하면 됨 |
| 2 | 이벤트명 (아래 표) | config classes와 동일 |
| 3 | `left` / `right` / 빈 문자열 | 궤적을 만든 손 (사용자 기준) |
| 4 | 신뢰도 (소수 2자리) | 현재 항상 1.00 |
| 5 | 엔진 단조시계 초 (소수 3자리) | 순서·중복 판별용 — 벽시계 아님 |

구분자 `|`는 값 안에 절대 등장하지 않는다 (필드 2·3은 영문 고정, 4·5는 숫자).

**이벤트 7종 (2026-07-23 확정 — 「제스처 정의 보고서」 손 모양 기준):**

| 이벤트명 | 사용자 동작 | UI가 할 일 |
|---|---|---|
| `left` / `right` / `top` / `bottom` | **한 손가락** + 좌/우/위/아래 쓸기 | 포커스 1칸 이동 (+ 새 항목 낭독) |
| `back` | **주먹** + 왼쪽 | 이전 화면 |
| `home` | **주먹** + 위 | 처음 화면 |
| `ok` | **주먹** + 오른쪽 | 현재 포커스 항목 실행 |

## 4. 델파이7 수신 구현 (표준 Windows API — 추가 부품 불필요)

핵심 절차: ① `CreatePipe`로 익명 파이프 생성 → ② `CreateProcess`로 엔진 실행
(STARTUPINFO의 `hStdOutput`에 파이프 쓰기 끝을 연결) → ③ 수신 스레드가
`ReadFile`로 읽어 CRLF 단위로 자른다 → ④ `PostMessage`로 메인 폼에 전달.

```pascal
// ①② 엔진 실행 + 파이프 연결 (요지 — 전체 코드는 delphi_ui/EngineProcess.pas)
var
  SA: TSecurityAttributes;  SI: TStartupInfo;  PI: TProcessInformation;
  ReadPipe, WritePipe: THandle;
begin
  SA.nLength := SizeOf(SA);  SA.bInheritHandle := True;  SA.lpSecurityDescriptor := nil;
  CreatePipe(ReadPipe, WritePipe, @SA, 0);
  FillChar(SI, SizeOf(SI), 0);
  SI.cb := SizeOf(SI);
  SI.dwFlags := STARTF_USESTDHANDLES or STARTF_USESHOWWINDOW;
  SI.hStdOutput := WritePipe;                  // 엔진 stdout -> 파이프
  SI.hStdError  := GetStdHandle(STD_ERROR_HANDLE);   // 로그는 그대로 콘솔/무시
  SI.wShowWindow := SW_HIDE;
  CreateProcess(nil, PChar('cmd /c run.bat'), nil, nil, True,
                CREATE_NO_WINDOW, nil, PChar(EngineDir), SI, PI);
  CloseHandle(WritePipe);   // 부모 쪽 쓰기 끝은 닫는다 — 안 닫으면 EOF가 안 온다
end;
```

```pascal
// ③④ 수신 스레드 — ReadFile 누적 버퍼를 CRLF로 잘라 메인 폼에 Post
// (바이트 처리는 AnsiChar/AnsiString — 델파이7·최신 델파이 겸용. 문자열은
//  GetMem 복사로 넘기고 수신 측이 FreeMem — 전체 코드: delphi_ui/EngineProcess.pas)
procedure TReadThread.Execute;
var
  Buf: array[0..1023] of AnsiChar;  Got: Cardinal;  Acc, Line: AnsiString;  P: Integer;
begin
  Acc := '';
  while ReadFile(FReadPipe, Buf, SizeOf(Buf), Got, nil) and (Got > 0) do
  begin
    SetString(Line, PAnsiChar(@Buf[0]), Integer(Got));
    Acc := Acc + Line;
    P := Pos(AnsiString(#13#10), Acc);
    while P > 0 do
    begin
      Line := Copy(Acc, 1, P - 1);
      Delete(Acc, 1, P + 1);
      if Copy(Line, 1, 8) = 'GESTURE|' then
        PostMessage(FormHandle, WM_GESTURE_EVENT, 0, LPARAM(NewAnsiLine(Line)));
      P := Pos(AnsiString(#13#10), Acc);
    end;
  end;
end;
```

```pascal
// 메인 폼 — 파싱(Pos/Copy)과 분기 (전체: delphi_ui/MainForm.pas)
procedure TForm1.WMGestureEvent(var Msg: TMessage);
var
  Line, EventName: string;  P: Integer;
begin
  Line := ...;                              // 메시지에서 문자열 회수
  P := Pos('|', Line);  Delete(Line, 1, P); // 'GESTURE' 제거
  P := Pos('|', Line);  EventName := Copy(Line, 1, P - 1);

  if EventName = 'left'   then MoveFocus(-1, 0)
  else if EventName = 'right'  then MoveFocus(+1, 0)
  else if EventName = 'top'    then MoveFocus(0, -1)
  else if EventName = 'bottom' then MoveFocus(0, +1)
  else if EventName = 'ok'     then ActivateFocused
  else if EventName = 'back'   then GoBack
  else if EventName = 'home'   then GoHome;
end;
```

주의사항:
- **UI는 메인 스레드에서만** — 수신 스레드에서 컨트롤을 직접 만지지 말 것 (PostMessage 필수).
- 엔진 종료·비정상 종료 시 `ReadFile`이 0을 돌려주며 스레드가 끝난다 —
  타이머로 감지해 엔진 재실행(재기동 루프) 권장.
- UI 종료 시 `TerminateProcess`(또는 파이프 닫기)로 엔진도 함께 종료할 것.

## 5. 델파이 없이 규격 확인 (자가 검증)

```
python scripts\pipe_listen.py
```

델파이가 할 일(자식 프로세스 + 파이프 수신)을 그대로 흉내 내는 도구다.
카메라 앞에서 제스처를 하면 `[RECV] GESTURE|right|right|1.00|...` 가 찍히면 정상.
엔진 화면(카메라·계기판)을 보면서 확인하려면 별도 창에서 `python scripts\run_demo.py --debug`.

## 6. 알려진 한계 / 협의 항목 (№7)

- 파이프는 전달 보장 — UDP 유실 정책 협의는 소멸. 남은 협의: 이벤트 7종의
  화면별 처리(첫 화면에서 back/home 무시 등 — delphi_ui/ 데모의 정책 참고).
- 음성 안내(TTS)는 엔진에서 제거됨(2026-07-22) — 낭독은 회사 UI가 자체 구현.
- 회사에서 별도 파이프 규격(명령 채널 등)을 정하면 `event_sender.py`에 Sender
  1개 추가로 대응 — 파이프라인 수정 불필요.
