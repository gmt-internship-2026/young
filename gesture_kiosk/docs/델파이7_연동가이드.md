# 델파이7(Delphi 7) 연동 가이드 — 제스처 엔진 ↔ 회사 GUI 프로그램

> 2026-07-20 확정: 회사 키오스크 GUI = 델파이7 네이티브 프로그램.
> 델파이7은 JSON 표준 지원이 없으므로 **텍스트 한 줄 규격**으로 연동한다.
> 엔진 쪽 구현: `src/pipeline/event_sender.py` (`build_text_payload`).
>
> **2026-07-21 갱신 — 웹소켓 전환(회사 결정)**: 시선추적 엔진과의 수신부 통일을 위해
> 웹소켓(`ws://<엔진IP>:5000/ws/events`)이 기본 채널이 된다. **메시지 내용은 UDP와
> 바이트 동일**(아래 §3 규격 그대로)이라 파서는 한 벌이면 된다. 과도기에는 UDP도
> 병행 송신된다. 전제: 델파이7용 웹소켓 클라이언트 부품 확보(§4-2).

## 1. 통신 구조

```
제스처 엔진 (python)                 델파이7 GUI 프로그램
  이벤트 확정 ──UDP 텍스트──────►  TIdUDPServer (포트 9999 수신)
  TTS 안내    ◄──HTTP POST──────  TIdHTTP  POST /announce (선택)
```

- 이벤트(엔진→GUI): **UDP 데이터그램**, 이벤트 확정 순간 1건씩 push. 폴링 불필요.
- 음성 안내(GUI→엔진, 선택): 화면 맥락 문구를 엔진 TTS로 읽히고 싶을 때만.

## 2. 엔진 쪽 설정 (`configs/config.yaml`)

```yaml
event_output:
  mode: udp               # 윈도우 배포 브랜치 기본값
  udp:
    host: 127.0.0.1       # 델파이 프로그램이 도는 PC (같은 PC = 루프백)
    port: 9999
    format: text          # 델파이7 규격
```

브라우저 데모 UI(:5000)는 그대로 살아 있다 — 연동 디버깅용으로 병행 사용 가능.

## 3. 전송 규격 (text)

이벤트 1건 = UDP 데이터그램 1개 = ASCII 한 줄 (CRLF 종료):

```
GESTURE|이벤트명|손|신뢰도|시각\r\n
예) GESTURE|select|left|1.00|12345.678
    GESTURE|move_right|right|1.00|12346.912
```

| 필드 | 값 | 비고 |
|---|---|---|
| 1 | `GESTURE` 고정 | 규격 식별자 — 다른 줄은 무시하면 됨 |
| 2 | `move_left` `move_right` `select` `go_back` `go_home` | config classes와 동일 |
| 3 | `left` / `right` / 빈 문자열 | 궤적을 만든 손 |
| 4 | 신뢰도 (소수 2자리) | 현재 항상 1.00 |
| 5 | 엔진 단조시계 초 (소수 3자리) | 순서·중복 판별용 — 벽시계 아님 |

구분자 `|`는 값 안에 절대 등장하지 않는다 (필드 2·3은 영문 고정, 4·5는 숫자).

## 4. 델파이7 수신 샘플 (Indy 9 — D7 기본 포함)

폼에 `TIdUDPServer` 올리고: `DefaultPort = 9999`, `Active = True`,
`OnUDPRead` 이벤트에:

```pascal
procedure TForm1.IdUDPServer1UDPRead(Sender: TObject; AData: TStream;
  ABinding: TIdSocketHandle);
var
  Line, EventName, HandSide: string;
  P: Integer;
begin
  SetLength(Line, AData.Size);
  if AData.Size > 0 then
    AData.ReadBuffer(Line[1], AData.Size);
  Line := Trim(Line);                       // CRLF 제거

  // GESTURE|select|left|1.00|12345.678
  P := Pos('|', Line);
  if Copy(Line, 1, P - 1) <> 'GESTURE' then Exit;
  Delete(Line, 1, P);

  P := Pos('|', Line);
  EventName := Copy(Line, 1, P - 1);        // move_left/move_right/select/go_back/go_home
  Delete(Line, 1, P);

  P := Pos('|', Line);
  HandSide := Copy(Line, 1, P - 1);         // left/right/빈값 (나머지 필드는 필요 시 동일 방식)

  if EventName = 'move_left'  then PrevFocus
  else if EventName = 'move_right' then NextFocus
  else if EventName = 'select'     then SelectFocused
  else if EventName = 'go_back'    then GoBack
  else if EventName = 'go_home'    then GoHome;
end;
```

주의: `OnUDPRead`는 수신 스레드에서 불릴 수 있다 — UI를 직접 만지지 말고
`PostMessage`(사용자 메시지)로 메인 폼에 넘기는 것이 안전하다.

## 4-2. 웹소켓 수신 (2026-07-21 전환 — 기본 채널)

- 접속 주소: `ws://127.0.0.1:5000/ws/events` (엔진과 다른 PC면 IP 교체, 포트는 config demo_ui.port)
- 접속해 두면 이벤트 확정 순간 §3 규격의 텍스트 한 줄이 웹소켓 메시지로 온다 —
  **UDP와 파싱 코드 동일** (§4의 파싱부 재사용, 수신 이벤트만 웹소켓 클라이언트 것으로)
- 델파이7에는 웹소켓이 표준 탑재돼 있지 않다 — 사내에서 시선추적 연동에 쓰기로 한
  웹소켓 클라이언트 부품(라이브러리)을 그대로 사용할 것. 부품이 메시지 단위 수신
  이벤트(OnMessage 류)를 주면 §4 파싱부에 그대로 연결하면 된다
- 재접속: 연결이 끊기면(엔진 재시작 등) 클라이언트가 재접속해야 한다 — 타이머로
  주기 재시도(예: 2초) 권장. UDP 병행 기간에는 둘 중 하나만 처리(중복 주의 — ts_sec 비교)

## 5. 음성 안내 요청 (선택 — TIdHTTP)

```pascal
uses IdHTTP;
var
  Body: TStringStream;
begin
  // 한글은 UTF-8로 보내야 한다 (D7 기본 문자열은 CP949)
  Body := TStringStream.Create(UTF8Encode('{"text":"발급하기 버튼"}'));
  try
    IdHTTP1.Request.ContentType := 'application/json';
    IdHTTP1.Post('http://127.0.0.1:5000/announce', Body, nil);
  finally
    Body.Free;
  end;
end;
```

## 7. 알려진 한계 / 협의 항목 (№7)

- UDP는 전달 보장이 없다 — 같은 PC 루프백에선 실질 유실이 거의 없지만,
  중요 이벤트(select) 유실 정책(무시/시퀀스 번호 재전송)은 회사와 협의.
- 엔진 자동 TTS("선택했습니다")와 GUI 동작 불일치 가능성 — 안내 주체 협의(№7).
- 델파이 프로그램이 **다른 PC**에서 돌면 host를 그 PC IP로 바꾸고 방화벽 UDP 9999 허용.
