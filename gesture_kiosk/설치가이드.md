# 설치가이드 — gesture_kiosk 추론 (윈도우 — CPU 단독)

다른 윈도우 PC에 그대로 옮겨 실행하기 위한 가이드입니다.
명령은 전부 **이 폴더(gesture_kiosk) 안에서** 실행합니다.

2026-07-29 포즈 스택 제거(사용자 결정): 추론 모델은 **MediaPipe HandLandmarker
하나**(내장 TFLite/XNNPACK — CPU 전용)입니다. GPU·CUDA·torch가 전부 불필요해져
설치가 가볍고 빨라졌습니다 (구 GPU 자동 감지 통합판은 07-24~07-29).

| 항목 | 기준 |
|---|---|
| OS | Windows 10/11 64비트 |
| GPU | **불필요** — CPU 추론 (2026-07-29 포즈 제거로 GPU 스택 소멸) |
| Python | **3.11.5** (설치 시 "Add python.exe to PATH" 체크) |
| 카메라 | USB 웹캠 1대 (오토포커스 권장) |
| 마이크 | 불필요 (입력은 제스처뿐) |

> ⚠ KPI 30 FPS 충족은 **PC의 CPU 사양에 좌우**됩니다 — 설치 후
> `venv_win\Scripts\python scripts\benchmark.py`로 확인 (미달 시 G절 참고).
> MediaPipe 손 추론은 구 포즈 스택보다 가벼워 일반 사무용 CPU로 충분합니다.

## A. 인터넷이 되는 PC — 3단계

```bat
:: 1) 이 폴더를 통째로 복사해 온 뒤, 폴더 안에서:
install.bat

:: 2) 실행 (이벤트가 콘솔에 GESTURE| 줄로 찍히면 정상 — 디버그 창: run.bat --debug)
run.bat
```

`install.bat`이 하는 일: Python 3.11 확인 → 가상환경(venv_win) 생성 →
고정 버전 패키지 설치(mediapipe·opencv 등 — CPU 전용) → 손 모델 확보
(models/weights/hand_landmarker.task, 없으면 download_weights.py) → 설치 검증(smoke_test).

> 📄 **라이선스 (B안 유지, 2026-07-29 갱신)**: 스택 = MediaPipe(Apache-2.0) 단독 —
> 상업 사용 가능, 코드 공개(카피레프트)·화면 표시 의무 없음.
> 손 모양 판별도 자체 기하 규칙이라 추가 의존성이 없습니다 (README 라이선스 절 참고).

## B. 내부망(인터넷 차단) PC — 번들 반입

정부 민원발급기처럼 인터넷이 없는 PC는, **인터넷 되는 윈도우 PC에서 번들을 만들어**
통째로 반입합니다.

```bat
:: [인터넷 되는 윈도우 PC — 같은 Python 3.11]  이 폴더 안에서:
make_offline_bundle.bat
::  → wheelhouse\ (파이썬 패키지 휠 전부) 생성. 손 모델은
::  models\weights\hand_landmarker.task 파일 하나라 폴더 복사에 그대로 담긴다

:: 프로젝트 폴더 전체를 zip → USB/반입절차로 대상 PC에 복사

:: [대상 내부망 PC]  폴더 안에서 (wheelhouse가 있으면 자동으로 오프라인 설치):

```

> 번들 제작 PC와 대상 PC는 **같은 Python 3.11 / 64비트 윈도우**여야 합니다.
> (pip이 제작 PC 기준으로 휠을 받기 때문)

## D. 회사 키오스크 프로그램(UI) 연동 계약

엔진과 UI는 파이프(stdio) 하나로 만납니다. 수신부 완성 코드·이식 요령은
`docs/델파이7_연동가이드.md` §4 참고.

| 방향 | 통로 | 내용 |
|---|---|---|
| 엔진→UI | stdout 파이프 — `GESTURE|이벤트|손|신뢰도|시각` 한 줄 (CRLF) | 이벤트 6종: `left` `right` `select` `back` `home` `confirm` (2026-07-29 개편) |

- UI가 엔진을 자식 프로세스로 실행해 stdout을 읽습니다 (docs/델파이7_연동가이드.md).
- 포커스 이동은 상하좌우 4방향 — 격자 밖 이동 처리·항목 낭독(TTS)은 UI 책임입니다.
- 새 수신 규격(소켓/시리얼 등)이 정해지면 `src/pipeline/event_sender.py`에 Sender 1개를 추가하고
  config `event_output.mode`로 선택합니다 — 파이프라인 수정 불필요.

## E. 동작 기준 (2026-07-29 개편 — 상하 포커스 제거, 위=select, ok→confirm)

| 동작 | 판정 | 이벤트 |
|---|---|---|
| 포커스 이동 | **한 손가락**(종류 무관) + 좌/우/위 쓸기 | `left` `right` `select` |
| 이전 화면 | **주먹** + 왼쪽 쓸기 | `back` |
| 처음으로 | **주먹** + 위 쓸기 (화면 이탈은 주먹만) | `home` |
| 확인(실행) | **주먹** + 오른쪽 쓸기 | `confirm` |
| 사용자 손 선별 | 쪽별 가장 큰 손 + 연속성 우선(hand_select — ★한 명 사용 가정) | (이벤트 없음 — 상태) |

- 손 모양이 계층을(탐색/명령), 이동 방향이 기능을 정합니다 — 모든 이벤트 즉시 확정.
  아래 방향은 두 모양 다 정의 없음(무시 — 07-29 top/bottom 소멸).
- 팔 되돌리기(복귀)는 반대 방향 삼킴이 자동 무시 — 쓸기 사이에 멈출 필요 없음.
- 쓸기 임계는 어깨너비 배수(카메라 거리 무관, 근접 상한 캡), 한 번에 한 손만 인식.
- ⚠ 양손이 모두 없는 사용자의 조작 수단은 UI 자동 순회(스캐닝) 협의 필요 (TODO №1).


## E-1. 카메라 설치 기준 (2026-07-16 — 현장 설치 시 필수 확인)

쓸기 임계는 **어깨너비 배수**(2026-07-29부터 손 실측 크기 기반 가상 어깨 자)로
정규화돼 있어 카메라·사용자 거리가 달라져도 판정 기준이 자동 보정됩니다.
단, 아래는 소프트웨어로 보정할 수 없어 설치로 지켜야 합니다.

| 항목 | 기준 | 이유 |
|---|---|---|
| 사용자 거리 | 0.8 ~ 1.5 m | 팔 쓸기 궤적 끝이 프레임 밖으로 나가면 손 추적이 끊겨 인식 불가. 멀수록 손이 작아져 검출률 저하 |
| 프레임 구도 | 가슴~머리 + 양팔 쓸기 반경 포함 | 제스처하는 손(21점)이 궤적 내내 보여야 함 |
| 카메라 높이 | 사용자 가슴~눈높이 (약 1.2~1.5 m) | 내려보기 각이 15°를 넘으면 위/아래 쓸기가 눌려 보임 |
| 지향 | 사용자 정면 | 측면 각이 크면 손 모양(손가락) 판별이 어려워짐 |
| 조명 | 역광 회피 | 실루엣화되면 손 랜드마크 신뢰도가 떨어짐 |

설치 후 확인: 디버그 창(run.bat --debug)에서 사용자가 표준 위치에 섰을 때 손
박스·손 추적점(모양 라벨 (F)/(1))이 안정 표시되고, 끝까지 쓸어도 화면 안에 남는지.

## F. 개인정보 처리

2026-07-16 주민등록증 OCR 기능이 제거되어 **엔진은 개인정보를 다루지 않습니다** —
입력은 손 랜드마크(좌표 숫자)뿐이고, 카메라 프레임은 디스크에 저장하지 않으며,
이벤트에는 동작 이름(left/confirm 등)만 실립니다. 본인확인 절차는 회사 프로그램 담당.

## G. 문제 해결

| 증상 | 조치 |
|---|---|
| `install.bat`에서 Python을 못 찾음 | Python 3.11.5 설치 시 PATH 체크 누락 — 재설치 또는 `py -3.11` 확인 |
| 손 모델 없음 오류 (hand_landmarker.task) | `models\weights\hand_landmarker.task` 확인 — 없으면 인터넷 PC에서 `venv_win\Scripts\python scripts\download_weights.py` 후 파일 반입 |

| 캡처 FPS가 ~5에 묶임 | `windows_backend: msmf` 확인 (dshow는 카메라에 따라 무압축 YUY2로만 협상돼 USB 한계에 걸림) |
| 30 FPS 미달 | config `model.max_infer_fps` 60→30 (캡처 스레드와 CPU 경합 완화 — 07-10 실측 주석 참고) |
| 다른 사람 손에 반응 | 한 명 사용 가정의 크기+연속성 선별이 기본 방어 — 상시 다중 인원 구도면 docs/TODO.md №1-2 (포즈 잠금 구판) 협의 |

## H. 델파이7 설치 (키오스크 UI 빌드·연동용)

엔진 자체는 델파이가 필요 없습니다 — 델파이7은 **UI 쪽**(회사 키오스크
프로그램에 수신부 이식·수정) 작업을 하는 PC에만 설치합니다.

### H-1. 준비물

- **회사 보유 델파이7 정품 설치 매체(CD 또는 ISO) + 시리얼 번호(Serial No.) + 인증 키(Authorization Key)**
- 델파이7(2002, Borland)은 단종 제품이라 **공식 다운로드가 없습니다** — 매체는
  회사 UI 담당자(자산 관리)에게 요청하세요.
- ⚠ 블로그 등 출처 불명 zip 설치본은 라이선스 문제 + 파일 변조 위험 —
  회사 작업·시연·납품에 사용 금지

### H-2. 설치 절차 (윈도우 10/11 기준)

```
1) 설치 매체의 INSTALL.EXE(또는 setup.exe) 우클릭 → "관리자 권한으로 실행"
2) 시리얼 번호·인증 키 입력
3) 설치 경로: C:\Program Files 밖을 권장 — 예: C:\Borland\Delphi7
   (구형 IDE는 설치 폴더 안에 설정 파일을 쓰기 때문에, Program Files에 넣으면
    UAC 가상화로 설정 저장이 꼬일 수 있다)
4) 구성은 Typical(기본)로 설치
```

### H-3. 설치 후 첫 설정 (한 번만)

```
1) 첫 실행은 우클릭 → "관리자 권한으로 실행" (레지스트리 초기 등록)
2) IDE 창이 깨지거나 오동작하면: Delphi32.exe 우클릭 → 속성 → 호환성
   → "Windows XP SP3" 호환 모드 체크
3) 에디터 폰트를 한글 지원 폰트로: Tools → Editor Options → Display
   → Editor font = 굴림체 (기본 Courier New는 한글이 깨져 보임)
4) 시스템 로캘이 한국어인지 확인 — 자세한 절차와 한글 깨짐 대처는
   docs\델파이7_연동가이드.md §5 "문제 해결 — 한글 깨짐" 참고
```

### H-4. 설치 확인

```
1) File → New → Application → F9  → 빈 폼이 뜨면 IDE 정상
2) 새 VCL 프로젝트에 docs\델파이7_연동가이드.md §4 수신부를 붙여 F9
```

### H-5. 대안 — 델파이 13 Community Edition (테스트·검증용)

델파이7 정품 매체가 없는 PC(동료 노트북 등)에서 **수신부 빌드·연동 검증까지만**
할 때는 무료 최신판으로 대신한다. 연동가이드 §4 수신부 코드는 신·구 델파이
겸용(AnsiChar/AnsiString 명시)이라 그대로 컴파일된다
(블로그 등 출처 불명 델파이7 zip은 쓰지 말 것 — H-1 주의).

```
1) embarcadero.com → Products → Delphi → Community Edition 다운로드
   (이메일 등록 → 무료 라이선스 키가 메일로 온다. 버전이 "13" 등
    최신 번호로 표시되는 것이 정상 — 델파이7이 아니어도 된다)
2) 설치 — 기본값(Delphi / Windows 32-bit 타깃)이면 충분.
   용량 수 GB·시간 소요, 설치 중 라이선스 키 입력
3) 새 VCL 프로젝트에 docs\델파이7_연동가이드.md §4 수신부를 붙여 F9
```

용도 한계 (반드시 지킬 것):
- **테스트·검증 전용** — 회사 키오스크 프로그램(델파이7 프로젝트)은 13으로 열지
  말 것: 프로젝트가 최신 형식으로 업그레이드돼 되돌리기 번거롭다.
  이식·최종 확인·납품 빌드는 H-1~H-4의 델파이7로 한다
- 저장할 때 인코딩을 물으면 **ANSI 유지** (UTF-8로 바꾸면 델파이7 호환이 깨진다)
- 한국어 윈도우에서 빌드 (회사 프로젝트 소스가 CP949)
- 13에서 컴파일돼도 마지막엔 회사 델파이7에서 F9 1회 확인이 정석
  (13이 더 관대해서 13 통과 ≠ 델파이7 통과 보장)

## I. 폴더 구조 (추론)

```
gesture_kiosk/
├─ install.bat / run.bat / make_offline_bundle.bat   # 이식·실행 진입점
├─ 설치가이드.md                                      # 이 문서
├─ requirements.txt          # 고정 버전 (재현성)
├─ configs/config.yaml       # 모든 튜닝값 — 수정은 여기서만
├─ models/weights/           # hand_landmarker.task (8MB — 유일한 모델 파일.
│                            #  오프라인 반입 시 폴더 복사에 그대로 포함)
├─ src/
│   ├─ capture/              # 카메라 캡처 스레드
│   ├─ inference/            # 손 랜드마크 (MediaPipe HandLandmarker — 유일한 모델)
│   ├─ postprocess/          # 사용자 손 선별 + 손 모양 판별 + 동작 판정
│   ├─ pipeline/             # 실시간 루프 · 이벤트 전송(stdio)
│   └─ utils/
├─ scripts/                  # run_demo · pipe_listen · download_weights · benchmark · smoke_test · resource_report · eval_accuracy
└─ tests/                    # 단위 테스트 (카메라·모델 없이 실행 가능)
```
