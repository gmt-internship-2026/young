# 코드 설명서 — gesture_kiosk 추론 엔진 (2026-08-03)

> **누구를 위한 문서인가**: 이 코드를 처음 보는 사람이 "어느 파일이 무슨 일을
> 하는지, 고치고 싶은 게 있으면 어디를 열어야 하는지"를 10분 안에 잡게 하는 지도.
> 상세한 "왜"는 각 파일 첫머리 독스트링과 config 주석에 날짜와 함께 남아 있다 —
> 이 문서는 길잡이만 한다.

---

## 1. 한 장 요약 — 데이터가 흐르는 길

```
카메라(USB 웹캠)
  │  CameraStream — 별도 스레드가 프레임을 계속 읽는다 (끊기면 자동 재연결)
  ▼
전처리 Preprocessor — 거울 반전 (사용자 기준 좌/우 일치)
  │
  ├─▶ [머리 앵커 스레드] HeadDetector(포즈) — 초당 10회, 사용자 머리 위치 관측
  │        └─ 마스크·모자 무관 (몸 실루엣으로 잡음). 손 루프와 병렬 — FPS 영향 없음
  ▼
손 인식 HandTracker(MediaPipe) — 프레임 속 손들의 21점 랜드마크
  │        └─ 원거리면 앵커 주변만 잘라 추론(ROI 줌 — 먼 손도 크게 보이게)
  ▼
사용자 손 선별 HandSelector — "누구의 어떤 손을 볼 것인가"
  │   ① 앵커 게이트: 가장 가까운 사람의 팔 도달 반경 안 손만 통과 (옆 사람 차단)
  │   ② 단일 손 추적: 움직여서 지시한 손 **하나**를 연속성으로 고정
  ▼
동작 판정 GestureFilter — "그 손이 무슨 동작을 했는가"
  │   손 모양(주먹/한 손가락/손바닥) × 쓸기 방향 + 제자리 더블 탭
  ▼
이벤트 전송 event_sender — stdout에 한 줄 출력 → 델파이 UI가 파이프로 수신
```

실행 진입은 **main.py** 하나다. 델파이(또는 사람이) `python.exe main.py`로 띄우면
위 파이프라인이 스레드로 돌고, 이벤트가 stdout에 한 줄씩 나온다.

## 2. 폴더·파일 지도

```
gesture_kiosk/
├─ main.py                ★공식 진입점 — 엔진 시작, 카메라 창 토글(cam on/off),
│                           콘솔 터치 먹통 방지(QuickEdit 해제)
├─ configs/config.yaml    ★모든 튜닝값의 단일 출처 — 숫자는 전부 여기 (코드에 하드코딩 금지)
├─ install.bat            설치(venv 생성 + 오프라인/온라인 패키지 + 모델 + 검증)
├─ run_debug.bat          현장 진단용 더블클릭 (창 켠 채 시작 + 크래시 시 창 유지)
├─ make_offline_bundle.bat  내부망 반입용 번들(wheelhouse) 제작 — 인터넷 PC에서

│
├─ src/
│  ├─ capture/            [카메라]
│  │  ├─ camera_stream.py   카메라 열기·협상(해상도/FPS/포맷)·프레임 읽기 스레드·
│  │  │                     끊김 자동 복구. "카메라가 안 열려요"는 여기와 config camera 절
│  │  └─ camera_probe.py    (카메라 2대일 때) 시작 시 장치별 손 인식 품질 채점 →
│  │                        좋은 카메라 자동 선택. 오픈 무한 대기 방지 시간 한도 포함.
│  │                        카메라 1대 확정이라 기본 꺼짐(config auto_select.enabled)
│  ├─ inference/           [모델 추론]
│  │  ├─ hand_tracker.py    MediaPipe 손 21점 랜드마크 — 유일한 주 추론 모델
│  │  ├─ head_detector.py   MediaPipe 포즈로 머리(귀 중점·폭) 관측 — 앵커의 관측원
│  │  └─ preprocessor.py    거울 반전 등 프레임 가공
│  ├─ postprocess/         [판정 — 엔진의 두뇌]
│  │  ├─ hand_select.py     ★사용자 손 선별: 앵커 게이트(옆 사람 차단) +
│  │  │                     단일 손 추적(획득/이음/해제) + 거리 자(가상 어깨너비) +
│  │  │                     어깨선 추정(카메라 거치 무관 위 쓸기)
│  │  ├─ gesture_filter.py  ★동작 판정: 쓸기 궤적(첫 선 방향 고정·플릭)·손 모양
│  │  │                     래치·들어올리기 게이트·복귀 삼킴·탭 클릭·쿨다운
│  │  ├─ hand_shape.py      손 모양 판별 기하 규칙: 주먹/한 손가락/손바닥/불명

│  ├─ pipeline/            [조립·연동]
│  │  ├─ realtime_loop.py   ★전체 조립: 시작(모델·카메라 병렬 오픈) → 추론 루프
│  │  │                     스레드 + 머리 앵커 스레드 + ROI 줌 창 관리
│  │  └─ event_sender.py    이벤트 → stdout 한 줄 (델파이 파이프 규격)
│  └─ utils/               [공통]
│     ├─ config_loader.py   config.yaml 로딩
│     ├─ logger.py          로그 (파일 logs/ + 콘솔은 경고만 — stdout은 이벤트 전용)

│  ├─ smoke_test.py         설치 검증 (카메라 없이 — install.bat이 호출)
│  ├─ benchmark.py          추론 단독 FPS 실측 (KPI 30 FPS 확인)
```

## 3. 핵심 개념 사전 — 코드를 읽을 때 만나는 단어들

| 개념 | 한 줄 설명 | 코드 위치 |
|---|---|---|
| **앵커(anchor)** | "지금 사용자는 이 사람" — 가장 가까운 머리를 고정하고, 그 사람 팔 도달 반경 밖 손은 차단 | hand_select `_update_head_anchor`, `_filter_hands_by_anchor` |
| **단일 손 추적** | 좌/우 라벨 없이 손 **하나**를 위치 연속성으로 추적. 획득=움직여 지시한 손, 해제=2초 소실 | hand_select `_update_tracked_hand`, `_acquire_tracked_hand` |
| **거리 자(尺)** | 판정 임계를 픽셀이 아니라 "어깨너비 배수"로 — 카메라 거리가 달라져도 같은 동작 = 같은 판정 | hand_select `hand_scale_ratio` |
| **손 모양 래치** | 판별 깜빡임 방지 상태기 — 저속에서 고정, 이동 중 동결, 연속 확인 시에만 전환 | gesture_filter `_update_shape_latch` |
| **첫 선(first line)** | 원점을 떠나는 첫 이동 벡터로 방향 확정 — 사람마다 다른 궤적 스타일 흡수 | gesture_filter `_SwipeTracker._update_first_line` |
| **들어올리기 게이트** | 팔 드는 준비 동작이 "위 쓸기"로 오발되지 않게 — 휴식 존(어깨선 아래) 직후 위 방향 무시 | gesture_filter `_stamp_rest_zone`, `_is_arm_raise` |
| **복귀 삼킴** | 쓸고 되돌리는 팔이 반대 방향으로 오발되지 않게 — 직전 획 끝에서 시작한 반대 획 무시 | gesture_filter `_set_swallow` 계열 |
| **탭 클릭** | 한 손가락 제자리에서 검지 까딱 2회 = click — 판별이 finger→fist→finger로 출렁이는 것을 읽음 | gesture_filter `_update_tap_click` |
| **ROI 줌** | 원거리에서 앵커 주변만 잘라 손 추론 — 먼 손도 모델 입력에서 크게 | realtime_loop `resolve_roi_box` |
| **어깨선 추정** | 휴식 존을 화면이 아니라 몸 기준으로 — 카메라 거치 각도와 무관 | hand_select `shoulder_line_y_ratio` |

## 4. 이벤트 규격 (UI 계약 — 총 10종)

| 손 모양 | 좌 | 우 | 위 | 제자리 더블 탭 |
|---|---|---|---|---|
| 한 손가락 `(1)` | `left` | `right` | `select` | `click` |
| 주먹 `(F)` | `back` | `confirm` | `home` | — |
| 손바닥 `(5)` | `temp_left` | `temp_right` | `temp_top` | — |

- 아래 방향은 전 모양 공통 "정의 없음"(무시). 출력 형식은 config `event_output`
  (기본: 이벤트명 한 줄. 상세 규격 `GESTURE|이벤트|손|신뢰도|시각`은 format: text).
- 델파이 수신 코드·규격 상세: docs/델파이7_연동가이드.md

## 5. 자주 하는 작업 — 어디를 고치면 되나

| 하고 싶은 것 | 여는 곳 |
|---|---|
| 쓸기 민감도(얼마나 움직여야 인식) | config `gestures.swipe.min_dist_x/y_shoulder`, `flick_*` |
| 손 모양 판별이 너무 엄격/느슨 | config `hand_select.hand_shape` (실측 근거 주석 참고) |
| 옆 사람 손이 잡힘 / 내 손이 잘림 | config `head_anchor.reach_head_widths` (↓/↑) |
| 위 쓸기가 안 먹힘 / 들어올리기 오발 | config `head_anchor.shoulder_below_head_widths`, `gestures.swipe.raise_guard_*` |
| 탭 클릭 감도 | config `gestures.tap_click` (창·반경) + gesture_filter `TAP_DIP_MAX_SEC` |
| 원거리 인식 | config `hand_tracker.roi_zoom`, `min_detection_conf` |
| 카메라가 안 열림/느림 | config `camera` 절 (device_id·windows_backend·auto_select) |
| 새 이벤트(모양×방향) 추가 | hand_shape에 모양 규칙 → gesture_filter `EVENT_BY_SHAPE`에 매핑 → config `classes` → 델파이 분기문 |
| 새 전송 방식(소켓 등) | event_sender에 Sender 클래스 1개 추가 + config `event_output.mode` |
| 이벤트가 안 나올 때 원인 추적 | `cam on`으로 창 열고 계기판(SCALE/ARM/SWIPE/LATCH) 확인 → logs/ 파일 |

**수정 원칙** (CLAUDE.md): 숫자는 config에만 · 실측과 이유는 날짜와 함께 주석으로 ·
수정 후 `python -m unittest discover tests`(174건)가 카메라 없이 돌아야 한다.

## 6. 실행·연동 요약

```bat
:: 공식 실행 (델파이 연동 명령과 동일 — venv 활성화 불필요)
venv_win\Scripts\python.exe main.py

:: 실행 중 콘솔에 타이핑 (또는 델파이가 stdin 파이프로)
cam on      ← 카메라·계기판 창 열기
cam off     ← 창 닫기
quit        ← 엔진 종료
```

- 시선추적과 **가상환경을 통합**하면 python.exe 경로만 그 환경으로 교체
  (설치가이드 B-1). main.py는 특정 venv·작업 디렉터리에 묶이지 않는다.
- 시작 소요·병목은 로그에 찍힌다: `프로세스 기동 n초` → `시작 소요: 모델 n초 ·
  카메라 포함 총 n초` (카메라 오픈은 모델 로딩과 병렬).

## 7. 역사 요약 — "왜 이렇게 생겼나" 빨리 잡기

| 시점 | 결정 | 흔적 |
|---|---|---|
| 07-15 | 손가락 개수 → **팔 쓸기 기반** (배리어프리) | gesture_filter 전체 |
| 07-28 | 포즈 손 → **MediaPipe 손 모델** (유령 손·원근 오판 해결) | hand_tracker |
| 07-29 | **포즈 스택 제거** — MediaPipe 단독 (라이선스·용량) | 거리 자·하단 띠 폴백 등 대체 구조 |
| 07-30~31 | **앵커 도입** (옆 사람 차단) → 얼굴에서 **포즈 머리로** (마스크 무관) | head_detector, hand_select |
| 07-31 | **단일 손 추적** — 좌/우 라벨을 정체성 키에서 제거 (라벨발 버그 계열 소멸) | hand_select 재작성, gesture_filter 단순화 |
| 08-03 | **main.py 직접 실행** 체계 + 시작 병렬화 + 카메라 창 런타임 토글 | main.py, realtime_loop |

각 결정의 상세 근거는 해당 파일 독스트링과 git 커밋 메시지(한국어, 날짜 포함)에 있다.
"이 값 왜 이래?"는 십중팔구 config.yaml 주석에 실측 날짜와 함께 답이 있다.
