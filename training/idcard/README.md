# idcard — 주민등록증 인식 학습 (조건부)

추론(gesture_kiosk)의 EasyOCR이 현장 조건(조명·거리·카드 반사)에서 인식률 미달일 때만
가동한다. **실측 결과가 나오기 전에는 시작하지 않는다** (docs/TODO.md 🟡 절 참고).

## 접근 방향 (우선순위 순)

1. **무학습 개선 먼저** — 가이드 영역 확대/축소, `ocr.min_text_conf` 조정, 조명 보정
   (CLAHE), 카드 검출 후 원근 보정 전처리 추가. 학습 없이 해결되는 경우가 많다.
2. **카드 검출기 학습** — 프레임에서 카드 영역을 YOLO로 검출해 crop 정확도를 올린다.
   합성 데이터(make_synthetic.py)로 시작 — 배경 합성만으로 충분한 경우가 많다.
3. **숫자/텍스트 인식기 파인튜닝** — EasyOCR 인식기를 한국 신분증 서체로 파인튜닝.
   (EasyOCR 커스텀 학습 절차는 공식 저장소 trainer 참고 — 착수 시 조사)

## 개인정보 원칙 (중요)

- **실물 주민등록증 촬영 데이터셋 구축 금지**가 기본 — 합성 데이터 우선
- make_synthetic.py는 가짜 이름·검증공식에 맞춘 가상 번호로 카드 레이아웃을 렌더링한다
- 실물 데이터가 불가피하면 회사 개인정보 절차(№11) 승인 + 마스킹·폐기 계획 먼저
