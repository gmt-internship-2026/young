# delphi_ui — 델파이7 데모 UI 빌드·실행 안내 (2026-07-23)

파이프(stdio) 연동 + 포커스 이동의 **동작 증명용 데모**다. 회사 키오스크
프로그램(델파이7)에 넣을 수신부·포커스 로직을 그대로 담고 있다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `GestureKioskUI.dpr` | 프로젝트 파일 — 델파이7에서 이걸 연다 |
| `EngineProcess.pas` | ★ 엔진 실행 + 파이프 수신 스레드 (실전 이식 시 그대로 재사용) |
| `MainForm.pas` / `.dfm` | 데모 화면 — 이벤트 분기 + 2차원 포커스 이동 + 화면 전환 |

★ `.pas`/`.dpr`는 **ANSI(CP949) 인코딩**으로 저장돼 있다 — 델파이7은 UTF-8을
못 읽는다. 다른 편집기로 고칠 때 UTF-8로 재저장하지 말 것 (한글 주석·문자열 깨짐).
★ 소스는 **델파이7 + 최신 델파이(Community Edition) 겸용**이다 (2026-07-23 2차 —
파이프 바이트 처리를 AnsiChar/AnsiString으로 명시, GetMem/FreeMem 전달).

## 빌드 A — 회사 UI 장비 (델파이7 있음)

1. 이 폴더를 엔진 폴더(`gesture_kiosk\`) 안에 그대로 둔 채, 델파이7에서
   `GestureKioskUI.dpr` 열기
2. F9 (실행) — 그만이다. 추가 컴포넌트·라이브러리 불필요 (표준 VCL + Windows API만 사용)

## 빌드 B — 델파이가 없는 PC (동료 윈도우 노트북 등)

델파이7은 2002년 상용 제품이라 공식 무료 다운로드가 없다 — 정품 매체가 없으면
**Embarcadero Delphi Community Edition(무료)** 으로 빌드한다.

> **버전 번호 안내**: 다운로드 페이지에 "Delphi 13" 등 최신 번호로 표시되는 것이
> **정상**이다 — 델파이7이 아니어도 된다. 이 폴더의 소스는 신·구 델파이 겸용으로
> 패치돼 있어(2026-07-23) 최신 버전에서 그대로 F9 컴파일된다. "델파이7"은
> 회사 키오스크 프로그램의 버전(= 최종 납품 기준)을 가리키는 말이다.

1. embarcadero.com → Products → Delphi → **Community Edition** 다운로드
   (이메일 등록하면 무료 라이선스 키가 메일로 온다)
2. 설치 — 기본값이면 충분 (Delphi / Windows 32-bit 타깃만 있으면 된다).
   용량 수 GB·시간 소요, 설치 중 라이선스 키 입력
3. 이후는 A와 동일: `GestureKioskUI.dpr` 열기 → F9

주의 (Community Edition):
- **한국어 윈도우에서 빌드할 것** — 소스가 CP949(ANSI)라 다른 언어 윈도우에선
  한글 리터럴이 깨진다
- IDE가 저장할 때 인코딩을 물으면 **ANSI 유지** 선택 (UTF-8로 바꾸면 델파이7 호환이 깨짐)
- 플랫폼은 기본 **Windows 32-bit** 그대로 (델파이7과 동일 동작)
- Community Edition은 무료지만 사용 조건(매출 상한 등)이 있는 라이선스다 —
  **사내 검증·데모용**으로 쓰고, 최종 기준·납품 빌드는 회사 델파이7이다

## 실행 전제 (엔진)

- 같은 PC에 엔진이 설치돼 있어야 한다: `gesture_kiosk\` 에서 `install.bat` 1회
  (윈도우 추론 브랜치 — 설치가이드.md 참고)
- 데모 UI는 시작 시 `..\run.bat`(= `ENGINE_COMMAND`, MainForm.pas 상단 상수)을
  자식 프로세스로 실행한다. exe 위치·엔진 경로가 다르면 그 상수 두 줄만 수정

## 동작 확인 순서

1. 실행하면 하단 로그에 `[엔진] 실행: cmd /c run.bat` 가 찍힌다
   (실패 시 3초마다 자동 재시도 — 상태 표시줄 확인)
2. **키보드 폴백으로 UI 먼저 검증** (엔진 무관): 방향키 = 포커스 이동,
   Enter = ok, Backspace = back, Home = home
3. 카메라 앞에서 제스처 — 로그에 `[수신] GESTURE|right|right|1.00|...` 줄이
   찍히고 포커스가 움직이면 연동 성공
4. 이벤트 7종: `left` `right` `top` `bottom`(한 손가락 4방향 — 포커스),
   `back`(주먹 왼쪽) `home`(주먹 위) `ok`(주먹 오른쪽)

## 문제 해결 — 한글 깨짐

깨지는 **위치**에 따라 원인·처방이 다르다:

| 어디가 깨지나 | 원인 | 해결 |
|---|---|---|
| GitHub·일반 편집기에서 소스 | 고장 아님 — CP949를 UTF-8로 해석한 것 | 조치 불요 (델파이에선 정상). VS Code는 우하단 인코딩 → Reopen with Encoding → Korean(EUC-KR) |
| **델파이 IDE 편집기에서 소스** | ① IDE 에디터 폰트가 한글 미지원 (D7 기본 Courier New는 한글 글리프 없음) ② 시스템 코드페이지가 CP949가 아님 | ① Tools → Editor Options → Display → Editor font를 **굴림체/돋움체**로 변경 ② 아래 "시스템 로캘 절차" |
| 실행된 UI (버튼·제목) | 폰트 문자셋 | 폼 폰트를 굴림+HANGEUL_CHARSET으로 고정해 둠(2026-07-23) — 최신 소스면 발생하지 않음 |

**시스템 로캘 절차** (재부팅 필요 — 요즘 노트북에서 가장 흔한 범인):

```
설정 → 시간 및 언어 → 언어 및 지역 → 관리 언어 설정 → [시스템 로캘 변경]
→ "한국어(대한민국)" 선택
→ ☐ "Beta: 세계 언어 지원을 위해 Unicode UTF-8 사용" 체크 해제   ← 핵심
→ 재부팅
```

이 Beta 옵션이 켜져 있으면 델파이7 같은 ANSI 프로그램이 CP949 대신 UTF-8로
해석해서 소스·화면 한글이 전부 깨진다.

> ⚠ 블로그 등 **출처 불명 zip 설치본**은 라이선스 문제 + 파일 변조 위험이 있다 —
> 개인 확인 용도까지만 쓰고, 회사 작업·시연·납품 빌드는 회사 정품 델파이7
> 또는 Community Edition(빌드 B)으로 할 것.

## 데모가 시연하는 정책 (회사 UI에 그대로 권장)

- 포커스는 격자(행×열)를 랩 없이 이동 — 끝에서 더 가면 "이동 없음" (예측 가능성)
- 첫 화면에서 back/home 무시 — 화면 이탈 사고 방지
- 수신 스레드는 UI를 직접 만지지 않는다 — `PostMessage` 로만 전달 (필수)
- UI 종료 시 엔진 프로세스도 함께 종료, 엔진이 죽으면 3초 내 자동 재실행

## 실전 이식 요령

1. `EngineProcess.pas` 를 회사 프로젝트에 추가 (수정 불필요)
2. 메인 폼에 `WM_GESTURE_EVENT` 핸들러를 달고 `MainForm.pas` 의
   `WMGestureEvent`(파싱)·`HandleEvent`(분기)를 복사
3. `MoveFocus`/`ActivateFocused` 를 실제 발급 화면의 컨트롤 목록에 연결
4. 포커스가 옮겨질 때 항목 낭독(TTS)은 UI 쪽에서 — 엔진에는 음성이 없다 (№7)
