# 설치가이드 — gesture_kiosk 추론 (윈도우 CPU — GPU 불필요)

다른 윈도우 PC에 그대로 옮겨 실행하기 위한 가이드입니다.
명령은 전부 **이 폴더(gesture_kiosk) 안에서** 실행합니다.

| 항목 | 기준 |
|---|---|
| OS | Windows 10/11 64비트 |
| GPU | **불필요** — CPU 추론판 (GPU 있는 PC는 feat/think_win_gpu 브랜치 권장) |
| Python | **3.11.5** (설치 시 "Add python.exe to PATH" 체크) |
| 카메라 | USB 웹캠 1대 (오토포커스 권장) |
| 마이크 | 불필요 (입력은 제스처뿐) |

> ⚠ CPU 추론판은 KPI 30 FPS 충족이 **PC의 CPU 사양에 좌우**됩니다 (실기 미검증 —
> benchmark로 확인할 것). 포즈 모델은 경량(lightweight)이 기본이며, 미달 시 G절 참고.
> GPU 있는 PC라면 **feat/think_win_gpu 브랜치**가 성능 기준입니다.

---

## A. 인터넷이 되는 PC — 3단계

```bat
:: 1) 이 폴더를 통째로 복사해 온 뒤, 폴더 안에서:
install.bat

:: 2) 실행 (이벤트가 콘솔에 GESTURE| 줄로 찍히면 정상 — 디버그 창: run.bat --debug)
run.bat

```

`install.bat`이 하는 일: Python 3.11 확인 → 가상환경(venv_win) 생성 →
onnxruntime 등 고정 버전 패키지 설치 → 포즈 모델 캐시 → 설치 검증(smoke_test).

> 📄 **라이선스 (B안, 2026-07-15 — 2026-07-23 재확인)**: 스택 = rtmlib/RTMPose(Apache-2.0)
> + ONNX Runtime(MIT) — 상업 사용 가능, 코드 공개(카피레프트)·화면 표시 의무 없음.
> 손 모양 판별도 자체 기하 규칙이라 추가 의존성이 없습니다 (README 라이선스 절 참고).

## B. 내부망(인터넷 차단) PC — 번들 반입

정부 민원발급기처럼 인터넷이 없는 PC는, **인터넷 되는 윈도우 PC에서 번들을 만들어**
통째로 반입합니다.

```bat
:: [인터넷 되는 윈도우 PC — 같은 Python 3.11]  이 폴더 안에서:
make_offline_bundle.bat
::  → wheelhouse\ (파이썬 패키지 휠 전부) + bundle_models\ (가중치) 생성

:: 프로젝트 폴더 전체를 zip → USB/반입절차로 대상 PC에 복사

:: [대상 내부망 PC]  폴더 안에서 (wheelhouse가 있으면 자동으로 오프라인 설치):
install.bat
run.bat
```

> 번들 제작 PC와 대상 PC는 **같은 Python 3.11 / 64비트 윈도우**여야 합니다.
> (pip이 제작 PC 기준으로 휠을 받기 때문)

## C. 실행 모드

| 명령 | 용도 |
|---|---|
| `run.bat` | 엔진 실행 — 이벤트가 콘솔(stdout)에 GESTURE 줄로 출력 |
| `run.bat --debug` | + 로컬 디버그 창 (카메라·판정 계기판 — 실기 튜닝용) |
| `venv_win\Scripts\python scripts\benchmark.py` | 추론 단독 FPS 측정 (KPI 30 FPS 확인) |

## D. 회사 키오스크 프로그램(UI) 연동 계약

엔진과 UI는 파이프(stdio) 하나로 만납니다. 완성 예제·이식 요령은 `delphi_ui/` 참고.

| 방향 | 통로 | 내용 |
|---|---|---|
| 엔진→UI | stdout 파이프 — `GESTURE|이벤트|손|신뢰도|시각` 한 줄 (CRLF) | 이벤트 7종: `left` `right` `top` `bottom` `back` `home` `ok` |

- UI가 엔진을 자식 프로세스로 실행해 stdout을 읽습니다 (docs/델파이7_연동가이드.md).
- 포커스 이동은 상하좌우 4방향 — 격자 밖 이동 처리·항목 낭독(TTS)은 UI 책임입니다.
- 새 수신 규격(소켓/시리얼 등)이 정해지면 `src/pipeline/event_sender.py`에 Sender 1개를 추가하고
  config `event_output.mode`로 선택합니다 — 파이프라인 수정 불필요.

## E. 동작 기준 (2026-07-23 확정 — 「제스처 정의 보고서」 손 모양 기준)

| 동작 | 판정 | 이벤트 |
|---|---|---|
| 포커스 이동 | **한 손가락**(종류 무관) + 상/하/좌/우 쓸기 | `top` `bottom` `left` `right` |
| 이전 화면 | **주먹** + 왼쪽 쓸기 | `back` |
| 처음으로 | **주먹** + 위 쓸기 (화면 이탈은 주먹만) | `home` |
| 확인(실행) | **주먹** + 오른쪽 쓸기 | `ok` |
| 사용자 고정 | 초점 맞은(선명·큰) 얼굴 기준 잠금 — 다른 사람 무시 | (이벤트 없음 — 상태) |

- 손 모양이 계층을(탐색/명령), 이동 방향이 기능을 정합니다 — 모든 이벤트 즉시 확정
  (구 아래 1회/2연속 분기·지연 제거). 주먹+아래는 정의 없음(무시).
- 팔 되돌리기(복귀)는 반대 방향 삼킴이 자동 무시 — 쓸기 사이에 멈출 필요 없음.
- 쓸기 임계는 어깨너비 배수(카메라 거리 무관, 근접 상한 캡), 한 번에 한 손만 인식.
- ⚠ 양손이 모두 없는 사용자의 조작 수단은 UI 자동 순회(스캐닝) 협의 필요 (TODO №1).


## E-1. 카메라 설치 기준 (2026-07-16 — 현장 설치 시 필수 확인)

쓸기 임계는 **어깨너비 배수**로 정규화돼 있어 카메라·사용자 거리가 달라져도
판정 기준이 자동 보정됩니다. 단, 아래는 소프트웨어로 보정할 수 없어 설치로 지켜야 합니다.

| 항목 | 기준 | 이유 |
|---|---|---|
| 사용자 거리 | 0.8 ~ 1.5 m | 팔 쓸기 궤적 끝이 프레임 밖으로 나가면 키포인트가 끊겨 인식 불가 |
| 프레임 구도 | 머리~골반 + 양팔 쓸기 반경 포함 | 어깨(정규화 자)·손(21점)·코가 모두 보여야 함 |
| 카메라 높이 | 사용자 가슴~눈높이 (약 1.2~1.5 m) | 내려보기 각이 15°를 넘으면 위/아래 쓸기가 눌려 보임 |
| 지향 | 사용자 정면 | 측면 각이 크면 어깨너비(정규화 자)가 좁게 잡힘 |
| 조명 | 역광 회피 | 실루엣화되면 포즈 키포인트 신뢰도가 떨어짐 |

설치 후 확인: 디버그 창(run.bat --debug)에서 사용자가 표준 위치에 섰을 때 USER LOCK
박스·손 추적점(모양 라벨 (F)/(1))이 안정 표시되고, 끝까지 쓸어도 화면 안에 남는지.

## F. 개인정보 처리

2026-07-16 주민등록증 OCR 기능이 제거되어 **엔진은 개인정보를 다루지 않습니다** —
입력은 포즈 키포인트(좌표 숫자)뿐이고, 카메라 프레임은 디스크에 저장하지 않으며,
이벤트에는 동작 이름(left/ok 등)만 실립니다. 본인확인 절차는 회사 프로그램 담당.

## G. 문제 해결

| 증상 | 조치 |
|---|---|
| `install.bat`에서 Python을 못 찾음 | Python 3.11.5 설치 시 PATH 체크 누락 — 재설치 또는 `py -3.11` 확인 |
| 카메라가 안 열림/수십 초 걸림 | config `camera.device_id` 0→1 변경, `camera.windows_backend`를 msmf↔dshow로 바꿔 시도 |
| 캡처 FPS가 ~5에 묶임 | `windows_backend: msmf` 확인 (dshow는 카메라에 따라 무압축 YUY2로만 협상돼 USB 한계에 걸림) |
| 30 FPS 미달 | config `input_size_px` 640→480, `pose_mode: lightweight` 확인 — 그래도 미달이면 GPU판(feat/think_win_gpu) 검토 |
| 다른 사람 팔에 반응 | 도달 거리 게이트 한도(`person_lock.reach_limit_shoulder`)를 줄인다 |

```

├─ install.bat / run.bat / make_offline_bundle.bat   # 이식·실행 진입점
├─ 설치가이드.md                                      # 이 문서
├─ requirements.txt          # 고정 버전 (재현성)

├─ src/
│   ├─ capture/              # 카메라 캡처 스레드
│   ├─ inference/            # 제스처 검출 + 사람 포즈
│   ├─ postprocess/          # 사용자 잠금 + 동작 판정(FSM)
│   ├─ pipeline/             # 실시간 루프 · 이벤트 전송 · 예시 UI 서버
│   └─ utils/
├─ scripts/                  # run_demo · download_weights · benchmark · smoke_test · export_onnx(개발용)
├─ delphi_ui/                # 델파이7 데모 UI — 파이프 수신·포커스 이동 예제
└─ tests/                    # 단위 테스트 (카메라·모델 없이 실행 가능)
```
